# Currate - AI-Powered Curation & Aggregation Platform

Welcome to Currate, the most advanced AI-powered curation and aggregation platform featuring Geter.ai technology and intelligent coupon aggregation.

## 🚀 Features

- **Geter.ai Engine**: Advanced AI algorithms for intelligent content curation
- **Smart Coupon Aggregation**: Automated discovery and validation of coupons
- **Real-time Processing**: Process millions of data points with <50ms response times
- **Enterprise Security**: SOC 2 Type II compliant with bank-grade encryption
- **API-First Platform**: Comprehensive REST APIs and SDKs
- **Advanced Analytics**: Deep insights and predictive metrics

## 🛠 Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS with custom animations
- **Animations**: Framer Motion for advanced interactions
- **Deployment**: Vercel (configured)
- **Architecture**: Modern JAMstack with server-side rendering

## 🏃‍♂️ Quick Start

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Aameer/curatte.git
cd currate

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📦 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
